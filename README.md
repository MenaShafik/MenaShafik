## About

I'm a Data Engineer based in Egypt. I completed ITI's Data Engineering track and build data pipelines and dimensional data warehouses, mainly with **SQL** and **Python**, using ETL/ELT patterns across on-premises and cloud platforms.

I hold the **Google Cloud Professional Data Engineer** certification, along with Microsoft Fabric, AWS and Apache Airflow credentials (below). My hands-on work spans data warehousing, workflow orchestration with **Apache Airflow**, and data processing with **Spark**.
